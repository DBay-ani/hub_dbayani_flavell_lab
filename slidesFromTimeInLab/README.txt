Text extracted from embedded content in PDFs was formed using the following commands run inside the directory holding the "pdfs" folder for the content here discussed.
Note that pdftotext does not perform OCR, so text that appears visually in pngs, etc., but that does not have corresponding embedded text will not be shown.
So be aware that simply because text does not appear in the output from pdftotext, it does not mean that content is not in the slides. The hope is that the
text extracted in this way may facilitate some searches, in particular if a keyword match occurs in the text provided, it is likely it exists in the slides
(though sometimes pdftotext screws up flattening text or special characters, etc., but the likelihood of that resulting in a false match seem far lower
the the likelihood of it producing a false miss). For those interested in full OCR, one could consider using the opensource software Tesseract 
(https://github.com/tesseract-ocr/tesseract) and discussions such as http://stackoverflow.com/questions/29657237/ddg#58339704 to see suggestions for feeding pdfs into it.  
```bash
mkdir pdftotext_outputOn_pdfs ;
for thisFile in $(ls -1 pdfs ); do pdftotext pdfs/$thisFile  pdftotext_outputOn_pdfs/$thisFile".txt" 2> pdftotext_outputOn_pdfs/stderr_$thisFile".txt" ; done
```
